# ✅ Popup Message

An animated **"Thank You" popup** that appears after clicking Submit — a common confirmation pattern for forms.

## ✨ Features

- Popup opens with a smooth animation on **Submit**
- Success icon, heading and message
- **OK** button closes the popup

## 🛠️ Built With

- HTML5
- CSS3 (transitions)
- JavaScript (Vanilla)
- [Font Awesome](https://fontawesome.com/)
